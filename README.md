# WeatherForcast

A SwiftUI-based weather forecast app that fetches weather data from Open-Meteo's free API.

## Features

- 🌍 Real-time weather search by city name
- 🕐 Hourly weather forecast with time navigation
- 📦 No API key required (uses Open-Meteo's public API)
- 🎨 Modern, clean UI built with SwiftUI

## Requirements

- iOS 15.0+
- Xcode 13.0+

## Usage

1. Enter a city name in the search bar
2. The app will automatically fetch weather data for that city
3. Use navigation buttons to browse through hourly forecast
4. View current weather conditions, temperature, and forecast

## Technologies

- **SwiftUI**: Modern declarative UI framework
- **Open-Meteo API**: Free weather API (no API key needed)
- **Combine**: Reactive programming for API calls
